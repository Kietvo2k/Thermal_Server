LLM orchestration on real machines

Run AI where the headroom is.

Send AI work to whichever machine is ready to take it — based on real temperature, not guesswork. Thermal Orchestrator watches telemetry from your Windows machines and only hands a complete LLM job to a node with the right model, spare headroom, and a READY state.

First-time setup needs Windows and a UAC prompt so NodeAgent can read sensors. The model downloads only when you pick it — nothing ships bundled with the installer.

Why thermal-aware dispatch

No painting the dashboard green with fake data, and no turning an inference into a measurement.

Workers only connect outward

Client machines push their own telemetry and pull their own jobs. No listening port is ever opened on a worker.

Measured stays separate from inferred

ESG keeps MEASURED, DERIVED, and PROJECTED apart — they are never combined into one flattering headline number.

Jobs only reach a model READY node

Model, hash, generation, and runtime must all match before a node is chosen to run a chat.
